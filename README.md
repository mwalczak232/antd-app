# antd-app

React + TypeScript + Vite app using [Ant Design](https://ant.design) v6.

```bash
npm install
npm run dev
```

## Ant Design MCP

`.mcp.json` configures the [official Ant Design MCP server](https://ant.design/docs/react/mcp) (`@ant-design/cli mcp`), pinned to the antd version in `package.json`. Claude Code picks it up automatically and asks you to approve the `antd` server on first use. Keep the `--version` arg in sync when you upgrade antd.
